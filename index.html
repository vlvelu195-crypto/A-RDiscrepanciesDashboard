How to get a GitHub token (one-time, about 2 minutes)
  1. Sign in to GitHub as vlvelu195-crypto (the account that owns the repository).
  2. Open Settings → Developer settings → Personal access tokens → Fine-grained tokens and click Generate new token.
  3. Name it e.g. “Discrepancy Tracker”, and pick an expiration date.
  4. Under Repository access, choose Only select repositories → A-RDiscrepanciesDashboard.
  5. Under Permissions → Repository permissions, set Contents to Read and write.
  6. Click Generate token, copy it, paste it below and click Save token.

If another admin works from a different GitHub account, the repo owner must first add them as a collaborator. They then use a classic token with the repo scope, because fine-grained tokens only cover repositories you own. Each admin connects once per browser; the token stays in that browser and is never written into the page or data.json.
